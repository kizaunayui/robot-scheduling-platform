# 机器人协同调度优化仿真平台

基于 React + Vite + Tailwind CSS 的医院多机器人协同调度与仿真管理系统。

## 功能模块

| 模块 | 说明 |
|------|------|
| 📊 系统首页 | 统计卡片、Canvas院区地图预览、任务趋势图、机器人状态饼图、操作日志 |
| 🏥 院区地图 | 3层楼医院地图可视化，Canvas交互，机器人实时位置，任务路径展示 |
| 🤖 机器人状态 | 机器人列表卡片，启动/暂停/重启操作，电量监控，状态分布统计 |
| ⚙️ 机器人配置 | 机器人参数配置，类型/速度/载重/电量阈值设置 |
| 📋 任务队列 | 任务列表管理，创建/派发/取消/加急操作，智能任务分配 |
| 📐 任务规划 | 地图选择起终点，Dijkstra路径规划，A/B/C三路径推荐，一键创建任务 |
| 📈 任务统计 | 完成率图表，类型分布，机器人工作量排行，任务明细 |
| 📝 操作日志 | 日志筛选搜索，重试失败操作，CSV导出 |
| 📡 设备监控 | 设备状态卡片，在线/离线/故障统计，设备详情面板 |
| 👥 用户权限 | 用户列表，角色权限管理，启用/禁用 |

## 技术栈

- **React 19** + **React Router 7**
- **Vite 8** 构建工具
- **Tailwind CSS 4** 样式
- **Canvas API** 地图渲染
- **recharts** 数据可视化
- **lucide-react** 图标

## 地图数据模型

- 3层楼医院地图（1200×800 像素/层）
- 每层16个节点（药房、手术室、病房、电梯厅、充电站等），共48个节点
- 57条边连接（含2条跨楼层电梯连接）
- 7个区域块（门诊区、急诊区、药房区、充电区、检验区、手术区、住院区），带限速和容量属性
- 10个运输机器人（4种类型：药品配送、样本转运、器械运输、医疗废物处理）

## 调度算法

- **任务分配**：基于机器人状态、类型匹配、电量、楼层距离的综合评分算法
- **路径规划**：Dijkstra最短路径算法，支持多路径生成（最优A/备用B/应急C）
- **冲突检测**：多机器人同楼层近距离路径交叉检测
- **负载均衡**：按机器人类型统计利用率
- **紧急插队**：高优先级任务队列插队机制

## 快速开始

```bash
npm install
npm run dev     # 开发模式
npm run build   # 生产构建
```

## 项目结构

```
src/
├── data/
│   └── mapData.js      # 医院地图数据模型（节点、边、区域、机器人）
├── utils/
│   └── scheduling.js    # 调度算法（任务分配、路径规划、冲突检测）
├── components/
│   ├── HospitalMap.jsx  # Canvas地图组件（交互式）
│   ├── Layout.jsx       # 布局组件
│   └── Sidebar.jsx      # 侧边栏导航（react-router-dom）
├── pages/               # 10个功能页面
├── store/
│   └── AppStore.jsx     # 全局状态管理（Context API）
├── App.jsx              # 路由配置（BrowserRouter）
└── main.jsx             # 入口
```
