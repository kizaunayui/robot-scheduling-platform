# 机器人协同调度优化仿真平台

基于 React 19 + Vite 8 + Tailwind CSS 4 的医院多机器人协同调度仿真系统。

## GitHub Pages

https://kizaunayui.github.io/robot-scheduling-platform/

## 核心功能（5 个页面）

| 模块 | 路由 | 说明 |
|------|------|------|
| 📊 调度总览 | `/` | KPI 卡片、网格地图预览、最近调度日志、一键运行/重置仿真 |
| 📋 任务调度中心 | `/tasks` | 创建任务、自动推荐机器人（评分+原因）、单任务派发/加急/撤销/完成全生命周期 |
| 🤖 机器人资源管理 | `/robots` | 4 台异构机器人（skills/capacity/container）、启停/回充/故障/恢复操作 |
| 🏥 院区调度仿真 | `/simulation` | Canvas 网格地图、机器人平滑移动动画、路径流光、冲突点标记、运行/单步/重置 |
| 📈 调度统计与日志 | `/statistics` | 类型/状态分布图表、工作量排行、调度指标、日志筛选与 JSON/CSV 导出 |

## 算法核心（从 simulator.py 移植）

- **A\* 搜索**：带时间约束的网格路径规划（含扩展次数上限，目标不可达时安全返回）
- **CBS 冲突消解**：多机器人冲突检测（vertex/edge conflict）与约束传播，冲突记录仅统计被采纳方案实际消解的冲突
- **机器人评分**：综合 skills 匹配、capacity、container、battery、distance、priority 的评分算法
- **智能调度**：支持批量调度与单任务定向派发（派发/加急/故障改派互不干扰队列中其他任务）
- **业务闭环**：任务完成后自动补派队列任务；空闲机器人低电量自动回充、充满自动恢复；全部完成后仿真自动停止
- **动态统计**：实时计算利用率、完成率、冲突数等指标

## 演示流程

1. 打开调度总览查看系统概览，点击「运行调度」
2. 在任务调度中心新增任务（类型/起点/终点/重量/优先级）
3. 系统自动推荐机器人（显示评分和推荐原因），可单条派发或加急
4. 院区调度仿真页查看机器人沿路径移动、冲突消解记录
5. 任务完成后机器人自动接手队列中的下一条任务，低电量自动回充
6. 调度统计与日志页查看图表、指标，导出 JSON/CSV

## 本地运行

需要 Node.js >= 20.19（建议 22，见 `.nvmrc`；低版本 npm 会静默跳过 rolldown 原生依赖导致构建失败）。

```bash
npm install
npm run dev
npm run build
```

## 当前限制

- 纯前端 mock 仿真，不接真实后端
- CBS 为简化实现（搜索预算 60 次扩展），非完整 CBS 论文算法
- 地图为网格化，非真实 CAD 地图
- 任务进度按时间片推进，机器人位置按进度沿路径插值，非物理仿真
