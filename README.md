# 机器人协同调度优化仿真平台

基于 React 19 + Vite 8 + Tailwind CSS 4 的医院多机器人协同调度仿真系统。

## GitHub Pages

https://kizaunayui.github.io/robot-scheduling-platform/

## 核心功能

| 模块 | 说明 |
|------|------|
| 📊 系统首页 | 动态统计卡片、网格地图预览、机器人/任务状态饼图、最近日志 |
| 🏥 院区地图 | Canvas网格地图、机器人实时位置、路径可视化、冲突点标记 |
| 🤖 机器人状态 | 4台异构机器人（药品配送/冷链标本/器械重载/被服运输）、skills/capacity/container属性、启停充电操作 |
| ⚙️ 机器人配置 | 机器人能力配置展示 |
| 📋 任务队列 | 创建任务、自动推荐机器人、派发/加急/撤销/推进/完成全生命周期 |
| 📐 任务规划 | CBS多机器人路径规划、A*搜索、冲突检测与消解、推荐分数和原因 |
| 📈 任务统计 | 动态图表：类型分布、状态分布、完成率、工作量排行 |
| 📝 操作日志 | 日志筛选搜索、CSV导出 |
| 📡 设备监控 | 从robots同步设备状态、电量、位置 |
| 👥 用户权限 | 用户角色管理 |

## 算法核心（从simulator.py移植）

- **A*搜索**：带时间约束的网格路径规划
- **CBS冲突消解**：多机器人冲突检测（vertex/edge conflict）与约束传播
- **机器人评分**：综合skills匹配、capacity、container、battery、distance、priority的评分算法
- **智能调度**：按优先级排序的批量任务分配
- **动态统计**：实时计算利用率、完成率、冲突数等指标

## 演示流程

1. 打开Dashboard查看系统概览
2. 在任务队列新增任务（选择类型/起点/终点/重量/优先级）
3. 系统自动推荐机器人（显示评分和推荐原因）
4. 派发任务 → 机器人状态变运行中 → 地图显示路径
5. 加急/推进/撤销/完成任务 → 统计/日志/设备同步更新
6. 在院区地图查看机器人位置、路径、冲突点

## 本地运行

```bash
npm install
npm run dev
npm run build
```

## 当前限制

- 纯前端mock仿真，不接真实后端
- CBS为简化实现，非完整CBS论文算法
- 地图为网格化，非真实CAD地图
- 机器人移动为路径展示，非实时动画
